# 📘 فاز ۱.۵: ورودی/خروجی (I/O) در جاوا – کامل و عمیق

I/O یکی از مباحث پایه‌ای جاواست که توی مصاحبه‌ها و کار روزمره خیلی用到 میشه. این بخش رو کاملاً جدا از مبانی جاوا می‌نویسم تا بتونی عمیق‌تر و متمرکزتر مطالعه کنی.

---

## ۱.۵.۱ مقدمه: I/O در جاوا چیست؟

جاوا برای کار با ورودی/خروجی (Input/Output) دو دسته کلی داره:

```text
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│                    Java I/O Architecture                            │
│                                                                     │
│  ┌─────────────────────────────┐  ┌─────────────────────────────┐   │
│  │     Byte-Oriented           │  │    Character-Oriented       │   │
│  │   (برای داده‌های باینری)     │  │    (برای داده‌های متنی)      │   │
│  │                             │  │                             │   │
│  │  InputStream  OutputStream  │  │   Reader       Writer       │   │
│  └─────────────────────────────┘  └─────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

#### فرق اصلی:

- Stream (بایت): برای فایل‌های باینری (تصویر، ویدیو، صدا، PDF)

- Reader/Writer (کاراکتر): برای فایل‌های متنی (TXT, CSV, JSON, XML)

### مثال‌های عملی با Byte Streams

#### ۱. FileInputStream (خواندن فایل)

```java
// a
// روش ۱: خواندن بایت‌به‌بایت
try (FileInputStream fis = new FileInputStream("image.jpg")) {
    int byteData;
    while ((byteData = fis.read()) != -1) {
        System.out.print(byteData); // مقادیر 0-255
    }
} catch (IOException e) {
    e.printStackTrace();
}

// روش ۲: خواندن تکه‌تکه (بهتر)
try (FileInputStream fis = new FileInputStream("image.jpg")) {
    byte[] buffer = new byte[1024]; // بافر ۱KB
    int bytesRead;
    while ((bytesRead = fis.read(buffer)) != -1) {
        System.out.println("خوانده شد: " + bytesRead + " بایت");
        // پردازش buffer[0] تا buffer[bytesRead-1]
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

#### ۲. FileOutputStream (نوشتن فایل)

```java
// b
// نوشتن بایت‌ها در فایل
try (FileOutputStream fos = new FileOutputStream("output.jpg")) {
    String text = "Hello World!";
    byte[] data = text.getBytes();
    fos.write(data);
    System.out.println("فایل ذخیره شد");
} catch (IOException e) {
    e.printStackTrace();
}

// کپی کردن فایل
try (FileInputStream fis = new FileInputStream("source.jpg");
     FileOutputStream fos = new FileOutputStream("dest.jpg")) {
    byte[] buffer = new byte[4096];
    int bytesRead;
    while ((bytesRead = fis.read(buffer)) != -1) {
        fos.write(buffer, 0, bytesRead);
    }
    System.out.println("فایل کپی شد");
} catch (IOException e) {
    e.printStackTrace();
}
```

#### ۳. BufferedInputStream/OutputStream (بهبود سرعت)

```java

    int bytesRead;
```

### ۱.۵.۴ Java NIO (New I/O - مدرن‌تر)

#### Java NIO (java.nio.*) از Java 1.4 اضافه شد و راه‌های مدرن‌تری برای I/O ارائه میده.

#### مقایسه IO و NIO

### مقایسه IO و NIO در جاوا

| ویژگی | IO (java.io) | NIO (java.nio) |
|-------|--------------|----------------|
| **جهت‌گیری** | Stream-oriented (یک‌طرفه) | Buffer-oriented (دوطرفه) |
| **بلوک‌شدن** | Blocking (مسدود) | Non-blocking (غیرمسدود) |
| **انتخاب‌گر** | ندارد | Selector (چند کانال) |
| **مناسب برای** | فایل‌های معمولی | سرورهای با ترافیک بالا |
| **API** | ساده‌تر | پیچیده‌تر ولی قدرتمندتر |

### مثال‌های NIO

```java
import java.nio.file.*;
import java.nio.*;

// ۱. خواندن همه خطوط (راحت‌ترین!)
List<String> lines = Files.readAllLines(Paths.get("file.txt"));
lines.forEach(System.out::println);

// ۲. نوشتن (راحت‌ترین!)
List<String> content = Arrays.asList("Hello", "World", "Line 3");
Files.write(Paths.get("output.txt"), content, StandardCharsets.UTF_8);

// ۳. کپی کردن فایل
Files.copy(Paths.get("source.txt"), Paths.get("dest.txt"), 
    StandardCopyOption.REPLACE_EXISTING);

// ۴. حذف فایل
Files.deleteIfExists(Paths.get("temp.txt"));

// ۵. چک کردن وجود فایل
if (Files.exists(Paths.get("file.txt"))) {
    System.out.println("فایل وجود دارد");
}

// ۶. خواندن کل محتوا به صورت String (Java 11+)
String content = Files.readString(Paths.get("file.txt"));
System.out.println(content);

// ۷. نوشتن String به فایل (Java 11+)
Files.writeString(Paths.get("output.txt"), "Hello World!", 
    StandardCharsets.UTF_8);

// ۸. لیست کردن فایل‌های یک پوشه
try (Stream<Path> paths = Files.list(Paths.get("."))) {
    paths.forEach(path -> System.out.println(path.getFileName()));
}

// ۹. ایجاد پوشه
Files.createDirectories(Paths.get("myapp/temp/logs"));

// ۱۰. دریافت اطلاعات فایل
Path path = Paths.get("file.txt");
System.out.println("نام: " + path.getFileName());
System.out.println("سایز: " + Files.size(path) + " بایت");
System.out.println("آخرین تغییر: " + Files.getLastModifiedTime(path));
System.out.println("نوع: " + Files.probeContentType(path));
```

### ۱.۵.۵ Object Serialization (ذخیره‌سازی اشیاء)

#### Serialization یعنی تبدیل یک شیء به جریان بایت برای ذخیره یا انتقال.

#### قوانین Serialization

- کلاس باید Serializable پیاده‌سازی کنه

- فیلدهای transient ذخیره نمیشن

- فیلدهای static ذخیره نمیشن

- کلاس باید serialVersionUID داشته باشه

#### مثال کامل

```java
import java.io.*;

// ۱. کلاس Serializable
class Person implements Serializable {
    private static final long serialVersionUID = 1L;
    
    private String name;
    private int age;
    private transient String password; // ذخیره نمیشه
    private static String company = "ACME"; // ذخیره نمیشه
    
    public Person(String name, int age, String password) {
        this.name = name;
        this.age = age;
        this.password = password;
    }
    
    // getters and setters
}

// ۲. Serialize (ذخیره)
public class SerializeExample {
    public static void main(String[] args) {
        Person person = new Person("Ali", 25, "secret123");
        
        try (ObjectOutputStream oos = new ObjectOutputStream(
                new FileOutputStream("person.ser"))) {
            oos.writeObject(person);
            System.out.println("شیء ذخیره شد");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

// ۳. Deserialize (بازیابی)
public class DeserializeExample {
    public static void main(String[] args) {
        try (ObjectInputStream ois = new ObjectInputStream(
                new FileInputStream("person.ser"))) {
            Person person = (Person) ois.readObject();
            System.out.println("نام: " + person.getName()); // Ali
            System.out.println("سن: " + person.getAge());   // 25
            System.out.println("پسورد: " + person.getPassword()); // null
        } catch (IOException | ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
}
```

### سفارشی‌سازی Serialization

```java
class Person implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private int age;
    private transient String password;
    
    // نوشتن سفارشی
    private void writeObject(ObjectOutputStream out) throws IOException {
        out.defaultWriteObject();
        out.writeUTF(password != null ? password : "default");
    }
    
    // خواندن سفارشی
    private void readObject(ObjectInputStream in) throws IOException, ClassNotFoundException {
        in.defaultReadObject();
        password = in.readUTF();
    }
}
```

## ۱.۵.۷ ❗️ سوالات مصاحبه‌ای پرتکرار

### ❓ سوال ۱: فرق InputStream و Reader چیه؟

#### جواب:

# مقایسه InputStream و Reader در جاوا

| ویژگی | InputStream | Reader |
|-------|-------------|--------|
| **کاربرد** | برای داده‌های باینری | برای داده‌های متنی |
| **واحد خواندن** | بایت (byte) می‌خواند | کاراکتر (char) می‌خواند |
| **کدگذاری** | ندارد | پشتیبانی از کدگذاری |
| **مقدار بازگشتی read()** | int read() برمی‌گردونه (0-255) | int read() برمی‌گردونه (0-65535) |
| **مثال** | تصویر، ویدیو | فایل TXT |

### ❓ سوال ۲: فرق FileInputStream و FileReader چیه؟

#### جواب:

```text
FileInputStream  →  برای فایل‌های باینری (تصویر، صدا، ویدیو)
FileReader       →  برای فایل‌های متنی (TXT, CSV)
```

### ❓ سوال ۳: BufferedReader چه مزیتی داره؟

#### جواب:

- بافرینگ: داده‌ها رو تکه‌تکه (بافر) می‌خونه، نه بایت‌به‌بایت

- سرعت بیشتر: به شدت سریع‌تر از FileReader معمولی

- متد readLine(): راحت‌ترین راه برای خواندن خط‌به‌خط


### ❓ سوال ۴: فرق transient و static در Serialization چیه؟

#### جواب:


### مقایسه transient و static در جاوا

| ویژگی | transient | static |
|-------|-----------|--------|
| **محدوده** | مخصوص هر شیء | متعلق به کلاس |
| **ذخیره در Serialization** | ذخیره نمیشه | ذخیره نمیشه |
| **کاربرد** | برای فیلدهای حساس (پسورد) | برای داده‌های اشتراکی |
| **مقدار پس از Deserialize** | `null` (یا مقدار پیش‌فرض) | مقدار کلاس (همان مقدار جاری) |

### ❓ سوال ۵: Try-with-Resources چه مشکلی رو حل می‌کنه؟

#### جواب:

- قبلش برای بستن منابع کلی کد تکراری می‌نوشتیم

- مدیریت دستی استثناها دردسر داشت

- ممکن بود یادمون بره منابع رو ببندیم (Memory Leak)

- حالا خودکار و امن بسته میشن

### ❓ سوال ۶: IO و NIO چه فرقی دارن؟

#### جواب:

# مقایسه IO و NIO در جاوا

| ویژگی | IO | NIO |
|-------|----|-----|
| **مبنای کار** | Stream-based (یک‌طرفه) | Buffer-based (دوطرفه) |
| **نوع عملکرد** | Blocking (مسدود) | Non-blocking (غیرمسدود) |
| **کاربرد مناسب** | فایل‌های معمولی | سرورهای بزرگ |
| **پیچیدگی API** | ساده‌تر | قدرتمندتر |
| **سرعت** | کندتر | سریع‌تر |

### ۱.۵.۸ خلاصه یک‌صفحه‌ای

# دسته‌بندی کلاس‌های I/O در جاوا

| مفهوم | کلاس‌ها | کاربرد |
|-------|---------|--------|
| **Byte Input** | `FileInputStream`, `BufferedInputStream`, `DataInputStream` | فایل‌های باینری |
| **Byte Output** | `FileOutputStream`, `BufferedOutputStream`, `DataOutputStream` | ذخیره باینری |
| **Text Input** | `FileReader`, `BufferedReader`, `InputStreamReader` | فایل‌های متنی |
| **Text Output** | `FileWriter`, `BufferedWriter`, `PrintWriter` | ذخیره متن |
| **Serialization** | `ObjectInputStream`, `ObjectOutputStream` | ذخیره اشیاء |
| **NIO** | `Files`, `Paths`, `Path` | روش مدرن I/O |
| **User Input** | `Scanner`, `BufferedReader`, `Console` | ورودی از کاربر |
